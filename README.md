## Topics Covered

- **C++ foundations:** control flow, functions, references, pointers, dynamic memory, function overloading
- **OOP:** abstract classes, polymorphism, templates
- **STL containers:** `array`, `vector`, `list`, `stack`, `queue`
- **Data structure implementation:** custom dynamic array with manual memory management
- **Algorithms:** Bubble Sort, Selection Sort, Insertion Sort, Quick Sort, Merge Sort
- **Analysis:** time complexity, execution time measurement, operation counting

## How to Use

1. Open any report from the [Lab Index](#lab-index) and download the `.docx` file.
2. Each report follows the same flow: task statement, C++ program, output.
3. To run a program, copy the code into any C++ compiler (g++, Visual Studio, Code::Blocks):

```bash
g++ program.cpp -o program
./program
```
